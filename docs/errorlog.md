# Error log

A curated list of real things that broke during the build, how each was found, what caused it and what changed. It is mined from `docs/FEEDBACK_DEBUGGING_SUMMARY.md`, the per-feature `logs/NN-*/errors.md` files and `git log`. Nothing here is reconstructed from memory; where the repository does not record a cause, the entry says so. Dates are commit dates (the first build ran 2026-05-02 to 2026-05-03).

Commit hashes are given where a fix is a commit. Per-feature test slips (wrong fixtures, off-by-one in tests) are grouped at the end instead of listed one by one.
